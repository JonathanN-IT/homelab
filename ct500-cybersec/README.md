# CT500 — Cybersécurité / OSINT

Conteneur dédié à la reconnaissance et l'investigation OSINT.

## Outils

- **SpiderFoot** — reconnaissance automatisée
- **Maigret** — recherche de comptes par pseudo
- **Holehe** — vérification d'emails sur services tiers
- **theHarvester** — collecte d'emails/sous-domaines/hosts
- **Recon-ng** — framework de reconnaissance web
